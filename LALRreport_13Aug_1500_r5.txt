How fire works (mental model)

For each episode’s ordered needs-LR samples:

if score ≥ θ for `dwell` consecutive samples → FIRE at that index
  if later claims LR (within K=4 or final hold) → false_give_up
  else → true_give_up
if never fires:
  if ever/final holds → true_hold
  elif gap looks lost → false_hold
  else → neutral_no_fire
