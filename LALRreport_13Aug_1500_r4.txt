• Grid-search on labeled episodes only.
• Predict give up if max_score of hopeless_score_lr ≥ θ.
• Primary = best F1 (then recall) on this batch.
• Fitted value 0.55 = named aggressive profile territory (Domain C freeze table: aggressive 0.55, balanced 0.65, safe 0.75).

Not the live default. Live SE uses safe 0.75 unless you retune Domain B.
